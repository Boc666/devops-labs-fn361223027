# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|
| Artifact | A built output of the pipeline, e.g. a package or image. / Резултат от изграждането, напр. пакет или образ. |
| Branch | An independent line of development in Git. / Независима линия на разработка в Git. |
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Commit | A saved snapshot of changes with a message. / Записано състояние на промените със съобщение. |
| Container | An isolated process with its own filesystem, started from an image. / Изолиран процес със собствена файлова система, стартиран от образ. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Merge | Combining the history of one branch into another. / Обединяване на историята на един клон в друг. |
| Pipeline | The automated sequence of build, test and deploy steps. / Автоматичната поредица от стъпки: изграждане, тестове, внедряване. |
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Release | A published version of the service, usually with a tag. / Публикувана версия на услугата, обикновено с таг. |
| Rollback | Returning the service to a previous working version. / Връщане на услугата към предишна работеща версия. |
| Runner | A machine that executes CI/CD jobs. / Машина, която изпълнява задачите на CI/CD. |
| Tag | A named pointer to a commit, used to mark releases. / Именуван указател към комит, за отбелязване на издания. |
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |
